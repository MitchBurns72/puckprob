Notre bilan

Est-ce que nos % disent vrai? Mis à jour le 1er novembre 2026

N'importe qui peut afficher des pourcentages. Ici, chaque prédiction est vérifiée après le match. Si on dit 70 % cent fois, ça devrait arriver environ 70 fois : la colonne « C'est arrivé » le montre, tranche par tranche.

Note /100 : 50 = pas mieux que donner le même % à tout le monde, 100 = parfait (impossible). Pour les joueurs, 55 à 60 est un bon modèle ; pour les victoires, même les meilleurs modèles publics tournent autour de 52 à 55, le hockey est très aléatoire. Bon côté : la part des fois où le côté jugé favori est arrivé.

Soirs comptés : 16 prédits avant les matchs, 18 rejoués après coup avec seulement les données disponibles avant le match (pour avoir plus d'historique dès le départ).
