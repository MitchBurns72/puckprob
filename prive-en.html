« Importer » : colle ici les bets que Claude te prépare à partir d'une capture de ton coupon. « Copier mes bets » : copie de secours de tout ce qui est sur cet appareil. Les bets déjà présents ne sont jamais doublés.

Comment lire ça

Note /100 : 50 = pas mieux que dire le même % à tout le monde. 100 = parfait, ça n'arrive pas. Pour les joueurs, 55 à 60 c'est un bon modèle. Pour les victoires, même les meilleurs modèles publics tournent autour de 52-55 : le hockey est très aléatoire. Sous 50, la version est à jeter pour ce marché.

Note globale : moyenne des notes de tous les marchés, pondérée par le nombre de prédictions. Les 4 seuils de tirs viennent des mêmes joueurs, ils comptent ensemble comme un seul marché.

Calibration : la barre bleue est le % réel dans chaque tranche, le trait rouge le % prédit moyen. La barre arrête au trait : le modèle dit vrai. Plus courte : trop optimiste.

Bon côté : % de fois où le côté jugé favori (50 % et plus) est arrivé. Pour les matchs, c'est le % de bons gagnants.

Brier : erreur moyenne au carré, plus bas = mieux. Les scratchés ne comptent pas.

Avec moins de 500 prédictions gradées (ou 150 matchs), les écarts entre versions peuvent être de la chance.
