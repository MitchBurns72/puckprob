# PuckProb

Probabilités LNH du soir : buts, passes, points, tirs, matchs, trophées et Coupe Stanley.
Que des pourcentages. Site indépendant, non affilié à la LNH.

Le site est calculé ailleurs et copié ici aux 20 minutes par `miroir.py`
(workflow « Miroir du site »). Il n'y a rien à modifier dans ce dépôt, à part `CNAME`
(le nom de domaine).
